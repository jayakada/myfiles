## How to use on GitHub
1. Extract this ZIP file.
2. Open your GitHub repository.
3. Upload the `CN_Semester_Experiments` folder and its contents (or upload the files directly into the repository).
4. Commit the changes.
5. Open `README.md` in GitHub.
6. Click any experiment link. For example, click **Experiment 3** to open the complete Experiment 3 answer.
