# Experiment 2
**Aim:** Develop a responsive layout using Flexbox and Grid.

Save as `2.html`:
```html
<!DOCTYPE html>
<html><head><title>Responsive Layout</title>
<style>
body{font-family:Arial;margin:0;background:#eee}
header{background:#333;color:white;padding:20px;display:flex;justify-content:space-between}
nav{display:flex;gap:15px} nav a{color:white}
.container{display:grid;grid-template-columns:repeat(3,1fr);gap:15px;padding:20px}
.card{background:white;padding:25px;text-align:center}
@media(max-width:768px){.container{grid-template-columns:repeat(2,1fr)}header{flex-direction:column}}
@media(max-width:480px){.container{grid-template-columns:1fr}nav{flex-direction:column}}
</style></head>
<body>
<header><h2>Responsive Web Design</h2><nav><a href="#">Home</a><a href="#">About</a><a href="#">Contact</a></nav></header>
<main class="container">
<div class="card">HTML</div><div class="card">CSS</div><div class="card">Flexbox</div>
<div class="card">Grid</div><div class="card">Responsive Design</div><div class="card">Web Development</div>
</main></body></html>
```
**Run:** Save as `2.html`, open in browser and resize the window.
**Output:** 3 columns on desktop, 2 on tablet and 1 on mobile.
**Result:** Responsive layout created using Flexbox, Grid and media queries.
