# Experiment 1
**Aim:** Design a static webpage using HTML and CSS.

Save as `1.html`:
```html
<!DOCTYPE html>
<html><head><title>My Web Page</title>
<style>
body{font-family:Arial;background:#eee;margin:0}
header,footer{background:#333;color:white;text-align:center;padding:18px}
nav{background:#555;padding:12px;text-align:center}
nav a{color:white;margin:15px}
.container{display:flex;gap:15px;margin:25px}
.box{background:white;padding:20px;flex:1;text-align:center}
</style></head>
<body>
<header><h1>Welcome to My Web Page</h1></header>
<nav><a href="#">Home</a><a href="#">About</a><a href="#">Contact</a></nav>
<div class="container">
<div class="box"><h2>HTML</h2><p>Page structure</p></div>
<div class="box"><h2>CSS</h2><p>Page styling</p></div>
<div class="box"><h2>Web Design</h2><p>Attractive pages</p></div>
</div>
<footer>Copyright 2026</footer>
</body></html>
```
**Run:** Save as `1.html` and open in a browser.
**Output:** Header, navigation, three content boxes and footer.
**Result:** Static webpage created using HTML and CSS.
