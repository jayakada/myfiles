# Experiment 3
**Aim:** Perform form validation and DOM manipulation using JavaScript.

Save as `3.html`:
```html
<!DOCTYPE html>
<html><body>
<h2 id="title">Registration Form</h2>
<form id="form">
Name: <input id="name"><br><br>
Email: <input id="email"><br><br>
Age: <input id="age" type="number"><br><br>
<button>Submit</button></form>
<p id="msg"></p>
<script>
document.getElementById("title").textContent="User Registration";
document.getElementById("form").addEventListener("submit",function(e){
 e.preventDefault();
 let n=name.value, em=email.value, a=age.value, m=msg;
 if(n==="") m.textContent="Enter name";
 else if(!em.includes("@")) m.textContent="Enter valid email";
 else if(a===""||a<18) m.textContent="Age must be 18 or above";
 else m.textContent="Registration Successful! Welcome "+n;
});
</script></body></html>
```
**Run:** Save as `3.html` and open in a browser. Test invalid and valid inputs.
**Output:** Error messages for invalid details and success message for valid details.
**Result:** Form validation and DOM manipulation performed successfully.
