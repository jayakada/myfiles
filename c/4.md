# Experiment 4
**Aim:** Retrieve server data asynchronously using AJAX without reloading the page.

Save as `4.html`:
```html
<!DOCTYPE html>
<html><body>
<h2>AJAX Web Application</h2>
<button onclick="loadData()">Load Data</button>
<div id="result">Click the button.</div>
<script>
function loadData(){
 let x=new XMLHttpRequest();
 x.open("GET","https://jsonplaceholder.typicode.com/posts/1",true);
 x.onload=function(){
  if(x.status===200){
   let d=JSON.parse(x.responseText);
   document.getElementById("result").innerHTML="<h3>"+d.title+"</h3><p>"+d.body+"</p>";
  }else result.textContent="Error loading data";
 };
 x.onerror=function(){result.textContent="Network error";};
 x.send();
}
</script></body></html>
```
**Run:** Save as `4.html`, open with internet access and click Load Data. If local-file access is blocked, use VS Code Live Server.
**Output:** Post title and body appear without refreshing the page.
**Result:** AJAX retrieves and displays data asynchronously.
