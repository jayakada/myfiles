# Experiment 7
**Aim:** Develop a full-stack Student Management application using HTML, JavaScript, Node.js, Express and MySQL.

**1. Create database:**
```sql
CREATE DATABASE studentdb;
USE studentdb;
CREATE TABLE students(id INT AUTO_INCREMENT PRIMARY KEY,name VARCHAR(100),email VARCHAR(100),department VARCHAR(100));
```
**2. Install packages:**
```bash
npm init -y
npm install express mysql2 cors
```
**3. Backend — save as `server.js`:**
```javascript
const express=require("express"),mysql=require("mysql2"),app=express();
app.use(express.json()); app.use(require("cors")()); app.use(express.static("public"));
const db=mysql.createConnection({host:"localhost",user:"root",password:"",database:"studentdb"});
db.connect(err=>console.log(err||"Database connected"));
app.post("/students",(req,res)=>{
 const {name,email,department}=req.body;
 db.query("INSERT INTO students(name,email,department) VALUES(?,?,?)",[name,email,department],err=>
 res.json({message:err?"Error adding student":"Student added successfully"}));
});
app.get("/students",(req,res)=>db.query("SELECT * FROM students",(err,data)=>res.json(data)));
app.listen(3000,()=>console.log("Open http://localhost:3000"));
```
**4. Frontend:** Create folder `public`; inside it save as `index.html`:
```html
<!DOCTYPE html>
<html><body>
<h2>Student Management System</h2>
<input id="name" placeholder="Name"><br><br>
<input id="email" placeholder="Email"><br><br>
<input id="dept" placeholder="Department"><br><br>
<button onclick="addStudent()">Add Student</button>
<h3>Student List</h3><ul id="list"></ul>
<script>
function loadStudents(){
 fetch("/students").then(r=>r.json()).then(data=>{
  list.innerHTML="";
  data.forEach(s=>{let li=document.createElement("li");
   li.textContent=s.name+" - "+s.email+" - "+s.department; list.appendChild(li);});
 });
}
function addStudent(){
 fetch("/students",{method:"POST",headers:{"Content-Type":"application/json"},
 body:JSON.stringify({name:name.value,email:email.value,department:dept.value})})
 .then(r=>r.json()).then(d=>{alert(d.message);loadStudents();});
}
loadStudents();
</script></body></html>
```
**5. Folder structure:**
```text
project/
  server.js
  public/
    index.html
```
**6. Run:** Execute `node server.js` in terminal and open `http://localhost:3000`.
**Output:** Enter student details, click Add Student; details are saved in MySQL and displayed.
**Result:** Full-stack student application created using frontend, backend, REST API and MySQL.
