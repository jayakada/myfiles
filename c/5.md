# Experiment 5
**Aim:** Create a server-side application using Node.js.

Save as `5.js`:
```javascript
const http=require("http");
const server=http.createServer((req,res)=>{
 res.writeHead(200,{"Content-Type":"text/html"});
 res.end("<h1>Welcome to Node.js Server</h1><p>Server is working.</p>");
});
server.listen(3000,()=>console.log("Server running at http://localhost:3000"));
```
**Run:** Install Node.js, open terminal in the file folder and execute:
```bash
node 5.js
```
Open `http://localhost:3000` in a browser.
**Output:** Browser displays “Welcome to Node.js Server”.
**Result:** Web server created successfully using Node.js.
